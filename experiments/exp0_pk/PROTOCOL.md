# exp0_pk: one-compartment drug kinetics with dosing, three compile targets from one specification

Written BEFORE any weight was set or any model trained (RULES.md R3, E1, E3). Governs `run_experiment.py`.

## Specification (the source of truth): `pk_spec.yaml`

Discrete time, DT = 1 s. State s = [A_depot, A_central, C_effect, tau_since_dose].
Inputs per tick u = [dose_to_depot, dose_to_central] (amounts, >= 0).
Per tick, in this order:
1. doses are added (depot for inhaled/IM, central for IV bolus);
2. kinetics advance: moved = A_depot (1 - e^{-ka dt}); A_depot -= moved; A_central += moved;
   A_central *= e^{-ke dt}; C_effect += (A_central - C_effect)(1 - e^{-keo dt});
3. tau_since_dose resets to 0 on a dose tick, else advances by dt;
4. readouts from the NEW state: effect E = Emax * C/(EC50 + C); heart-rate increment
   dHR = HRmax * C/(EC50_hr + C).

Parameters per patient variant: ka, ke, keo (as half-times in minutes), Emax, EC50, HRmax, EC50_hr.

## Compile targets
- **CODE** (control): `pk_code.py`, the rules above as ordinary Python. Ground truth by definition.
- **A2 / WSP**: `pk_wsp.py`, a 3-layer ReLU cell with hand-set weights built from the specification
  by explicit construction (linear recurrence exact; Emax readouts as ReLU interpolants with 24
  knots; dose gate as steep clip; tau as gated ramp). No training, no fitting, no search.
  Builder: the authoring frontier model (Claude Fable 5.1) in this session. A local-builder
  version of this step is the calibration test in `experiments/exp1_calibration/`.
- **D / trained**: `pk_trained.py`, a 2-hidden-layer MLP next-step model (64 units) trained with
  Adam on single-step transitions from the DEV trajectories only (teacher forcing), rolled out
  autoregressively at test time. Seed fixed. No held-out data touched during training or model
  selection.

## Splits (fixed in `splits.json`, generated by `make_splits.py` with seed 20261104 BEFORE building)
- DEV: 3 patient variants (typical, fast-absorber, slow-eliminator) x 8 dosing schedules
  (single dose; two doses 20 min apart; three doses 20 min apart; IV bolus; inhaled then IV; dose at
  t=0 then nothing for 90 min; two doses 5 min apart; irregular 4-dose), 60 to 90 min each.
- HELD-OUT: 3 NEW variants (extremes: ka half-time 0.5 min with EC50 0.2; ke half-life 600 min;
  keo link 10 min with HRmax 60) x 6 NEW schedules (10 doses at 6-min intervals (overdose),
  single dose then 180 min rollout, doses at 1, 2, 3 min then nothing, IV + inhaled same tick,
  alternating routes every 15 min, nothing at all for 60 min). Whole variants and whole schedules
  are held out, never neighbouring timesteps.

## Metrics (all vs CODE on the same inputs)
- max |E_target - E_code| and RMSE over every tick of every rollout (effect units, Emax = 1 scale)
- max relative error of C_effect
- state violations: any negative amount, NaN, or tau not resetting on a dose tick
- replay: two runs of the same rollout must be bit-identical
- causal consistency: for every dose tick t, C_effect(t + 60 s) > C_effect(t) (onset), and with no
  dose for 30 min after the absorption phase, C_effect is non-increasing
- long rollout: 180 min at 1 s (10,800 steps) without divergence
- parameter count, checkpoint bytes, wall time per 60-min rollout (CPU, this container)
- ledger: forward passes (one per rollout), design changes, builder runs

## Pass / fail (predefined)
- WSP passes if: max |dE| <= 0.01 on HELD-OUT, C_effect relative error <= 1e-9, zero violations,
  replay bit-exact, all causal checks pass, and <= 3 design changes were needed.
- TRAINED passes if: max |dE| <= 0.05 on HELD-OUT, zero violations, replay bit-exact, causal checks pass.
- CODE is the reference; its own checks are the violation and causal checks only.
- Revision limit: 3 logged design changes for WSP, 3 training-configuration changes for TRAINED.

## What result would change the recommendation
- If WSP fails on HELD-OUT extremes while CODE passes, weight compilation of even this linear
  model is not robust and the weight track is deprioritised.
- If TRAINED passes within 0.05 on all held-out extremes and long rollouts, conventional training
  from code-generated trajectories is a viable cheap target and deserves a follow-up with the
  respiratory model.
- Nothing in this experiment can show weights are *better* than code; it can only show whether
  they are *as exact* and what they cost. The "better on an instructor-visible criterion" question
  is deferred to exp2 (composability / calibration tests), as the brief requires.

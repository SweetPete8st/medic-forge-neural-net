# Construction notes (haiku2)

Network: 3 layers. Layers 1 and 2 are ReLU, layer 3 is linear. Input x = [A_d, A_c, C_e, tau, u_d, u_c].
Output y = [A_d', A_c', C_e', tau', E, dHR]. Generated by `build_haiku2.py` from the spec and the
per-variant parameters in `pk_spec_dev.yaml`. No training or fitting.

Constants (per variant, from k = ln2 / (half_min * 60), dt = 1):
- ea = exp(-ka dt) (so a = 1 - ea is the absorbed fraction per tick)
- p = exp(-ke dt)
- q = 1 - exp(-keo dt)
- S = 100 (dose-gate slope), BIG = 1e4 (must exceed tau + dt; rollouts are at most 5400 ticks)
- Readout knots: greedy, with chord error bound eps_E = 1e-3 (E) and eps_H = 2e-3 (dHR)

Why the ReLUs are exact: all states and inputs are >= 0 (the kinetics map non-negative quantities to
non-negative quantities), so every ReLU in layers 1 and 2 whose argument is a non-negative linear
combination acts as the identity on it. Only the gate and the readout hinges truly use ReLU's nonlinearity.

## Layer 1 (6 units; input order as above)
- H1[0] = u1 = ReLU(S*u_d + S*u_c). Gate upper ramp.
- H1[1] = u2 = ReLU(S*u_d + S*u_c - 1). Gate lower ramp. Dose gate g = u1 - u2 = min(1, S*(u_d+u_c)),
  which is exactly 1 for any dose >= 0.01 and exactly 0 for no dose.
- H1[2] = T = ReLU(tau + dt). Tau advanced by one tick (identity, since tau >= 0).
- H1[3] = A_d' = ea * (A_d + u_d). Step 1 (dose) plus step 2 (absorption), depot part.
- H1[4] = A_c' = p * (A_c + u_c + a*(A_d + u_d)). Central compartment after absorption and elimination.
- H1[5] = C_e' = (1-q)*C_e + q*A_c'. Effect compartment update, with A_c' substituted and expanded
  into the input coefficients q*p*a, q*p, 1-q.

## Layer 2
- H2[0] = tau' = ReLU(T - BIG*u1 + BIG*u2) = ReLU(T - BIG*g). Equals T when there is no dose, and
  ReLU(T - BIG) = 0 when there is a dose (since T <= BIG). This is the reset.
- H2[1] = ReLU(A_d') pass-through (identity, since A_d' >= 0).
- H2[2] = ReLU(A_c') pass-through.
- H2[3] = ReLU(C_e') pass-through.
- H2[4 .. 4+nE) = ReLU(C_e' - k_j) for the E interpolant knots k_0..k_{nE-1}. Hidden unit j of the
  piecewise-linear interpolant of f_E(C) = Emax*C/(EC50+C). Built with `interpolant_rows`.
- H2[4+nE .. ) = ReLU(C_e' - k_j) for the dHR interpolant of f_H(C) = HRmax*C/(EC50_hr+C), same method.

## Layer 3 (linear output)
- y0 = H2[1] (A_d'), y1 = H2[2] (A_c'), y2 = H2[3] (C_e'), y3 = H2[0] (tau').
- y4 = E = f_E(0) + sum_j w_j * H2[4+j], with f_E(0) = 0 and w_j the slope changes of the interpolant.
- y5 = dHR = sum_j w'_j * H2[4+nE+j], with f_H(0) = 0.

## Knot placement (how the chord error is controlled)
For f(C) = Hmax*C/(EC+C), f'' = -2*Hmax*EC/(EC+C)^3, so |f''| is largest at C = 0 and decreases.
On an interval [c, c+h] the chord error is at most h^2/8 * |f''(c)|. Greedy knots set h = sqrt(8*eps/|f''(c)|).
This gives spacing that grows like (EC+C)^1.5: fine near EC50, coarse far away. For E the bound is 1e-3 for
every variant, independent of EC50. Knots run to C = 20 (above the total dose in the dev schedules, 10.3,
which bounds C_e). Beyond the last knot the readout extrapolates linearly, which is not used in the dev schedules.
Knot counts: E 27/28/27, dHR 85/99/72 (typical / fast_absorber / slow_eliminator).

## Parameter count (sum of W.size + b.size)
- typical: 1556
- fast_absorber: 1751
- slow_eliminator: 1387
The count differs by variant only because the number of knots depends on EC50 and HRmax.

## Limits and assumptions
- Dose gating is exact for dose amounts >= 0.01. Dev doses are 0.3 to 5.0. A dose of 0.005 would give a
  fractional gate. The tau reset is only as exact as this gate.
- tau is limited to <= BIG - dt = 9999 s, which covers the 5400 s rollouts.
- Readouts are exact outside the chord error only for C within [0, 20]. Total dose bounds C_e.
- Float cancellation in the tau reset (BIG * S-scale terms) leaves tau with error around 1e-8 (self-check
  shows 0 at printed precision). tau does not feed E.

## What each variant changes
Only the constants (ea, p, a, q, knot positions and slopes via EC50/HRmax/EC50_hr, and the readout weights).
The topology is the same for all three variants.

# Construction notes (haiku attempt)

Generated by `attempts/haiku/build_weights.py` from `pk_spec_dev.yaml`. No training, no fitting.
All three networks share one architecture; only the variant constants (and the knot step) differ.

## Notation
- Input x = [A_d, A_c, C_e, tau, u_d, u_c] (6 values, all >= 0).
- Per variant: a_d = exp(-ln2/(ka_half_min*60)), a_c = exp(-ln2/(ke_half_min*60)), al = 1 - exp(-ln2/(keo_half_min*60)), with dt = 1.
- Architecture: layer 1 (6 ReLU units) -> layer 2 (4 + K ReLU units) -> output layer (6 linear units).

## Why the kinetics are exact with ReLU
Every pre-activation of the kinetics is a non-negative combination of non-negative quantities
(all rate constants are in (0,1], the dose amounts and states are >= 0). So the ReLUs on those
units are identities, and the linear kinetics are carried exactly. The composition is:
- doses added first: D = A_d + u_d, Cc = A_c + u_c
- moved = (1 - a_d) * D; A_d' = a_d * D; A_c' = a_c * (Cc + moved)
- C_e' = (1 - al) * C_e + al * A_c'  (the new effect-site concentration, used for the readouts)

## Layer 1 (6 hidden units, W1 is 6x6, b1 is 6)
- h0 = C_e' = (1-al)*C_e + al*a_c*A_c + al*a_c*u_c + al*a_c*(1-a_d)*(A_d + u_d). Identity ReLU (argument >= 0).
- h1 = A_d' = a_d*(A_d + u_d). Identity ReLU.
- h2 = A_c' = a_c*(A_c + u_c) + a_c*(1-a_d)*(A_d + u_d). Identity ReLU.
- h3 = G1 = ReLU(S*(u_d + u_c)) with S = 1000.
- h4 = G2 = ReLU(S*(u_d + u_c) - 1). G1 - G2 is exactly 1 when any dose is given (amount >= 1e-3) and exactly 0 otherwise. This is the dose indicator.
- h5 = tau pass-through = ReLU(tau).

## Layer 2 (4 + K hidden units, K = number of interpolant intervals)
- P0 = ReLU(h0) = C_e' (pass-through).
- P1 = ReLU(h1) = A_d' (pass-through).
- P2 = ReLU(h2) = A_c' (pass-through).
- T = ReLU(tau + dt - BIG*G1 + BIG*G2) with BIG = 1e4 and dt = 1. Without a dose the unit is tau + 1 (the ramp advances). With a dose it is ReLU(tau + 1 - BIG), which is 0 because tau <= 5400 s for 90-minute rollouts. So T = tau'.
- I_j = ReLU(h0 - k_j) for knots k_j = j*step, j = 0..K-1. These are the interpolant units for the nonlinear readouts. They are exact at the knots, and C_e' >= 0 keeps them exact.
  - step (per variant, chosen so that the chord-error bound is <= 2e-3 for both E and dHR): typical 0.02 (K=600), fast_absorber 0.01 (K=1200), slow_eliminator 0.02 (K=600). Knots cover C in [0, 12]. Dev schedules have total dose <= 10.3, so C_e stays in range.

## Output layer (linear, 6 units)
- y0 = A_d' = P1
- y1 = A_c' = P2
- y2 = C_e' = P0
- y3 = tau' = T
- y4 = E = sum_j w_E,j * I_j, where w_E are the slopes-differences of Emax*C/(EC50+C) on the knots (f(0)=0 so no bias).
- y5 = dHR = sum_j w_HR,j * I_j, the same construction for HRmax*C/(EC50_hr+C).

## Chord-error bound
For a piecewise-linear interpolant with step h, the error is <= h^2/8 * max|f''|. Here max|f''| = 2*Emax/EC50^2 (at C = 0), so the E bound is Emax*h^2/(4*EC50^2). The dHR bound is HRmax*h^2/(4*EC50_hr^2). The chosen steps give bounds of 1.1e-3 (typical), 7.5e-4 (fast_absorber) and 5.0e-4 (slow_eliminator). The step is picked as the largest value in [0.05, 0.02, 0.01, 0.005] whose bound is <= 2e-3. The knots are placed relative to EC50 and EC50_hr through this bound.

## Limitations
- Gate steepness S = 1000 is exact for dose amounts >= 1e-3. Smaller nonzero doses would give a fractional gate.
- The interpolant is only valid for C_e in [0, 12]. Above 12 it continues linearly with the last chord slope.
- Parameter count (sum of W.size + b.size): typical 7900, slow_eliminator 7900, fast_absorber 15700 (the knot count is set by the step).
